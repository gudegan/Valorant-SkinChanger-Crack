## 一句话
`VS.exe`(Themida 强壳)其实只是「启动器 + 本地 HTTP 后端」,真正的换肤接口 `POST /skin-changer` **未做鉴权**;本仓库把厂商网页在本地重托管并做小补丁,绕过登录/卡密,直接使用换肤功能。

## 快速开始
前置:自备正版 `VS.exe`(本仓库**不包含**厂商二进制)。

> ⚠️ **必须把 `一键启动.bat` 和整个 `crack` 文件夹一起** 放到 `VS.exe` 同目录。
> 只复制 bat、不带 `crack` 文件夹 → 会报 `Windows 找不到文件 ...\crack\_run_serve.bat`。

1. `一键启动.bat` + `crack\` 一起放进 **VS.exe 同目录**;
2. 双击 `一键启动.bat` → UAC 点“是”(后端需要管理员);
3. 自动:定位 crack 与 VS.exe → 关掉占用 8000 端口的旧前端 → 起本地前端 → 拉起 `VS.exe` → 打开 `http://127.0.0.1:8000/`;
4. 页面顶部出现红色横幅 **“V6 破解版已生效”** 即成功;若提示登录,账号密码随便填,点登录即可。

脚本会在 同目录 `crack\`、`..\crack`、`extract\crack`、上级目录 里自动找 crack(找不到给中文提示,不再弹系统“找不到文件”对话框),所以目录结构不用跟本文一模一样。

> 也可手动:先开 `VS.exe`,再 `python crack/v6serve.py`,浏览器开 `http://127.0.0.1:8000/`。

## 原理(简)
本机后端只监听 `[::1]:8080`;前端判定登录只靠 `localStorage.isAuthenticated` 与 `GET /ping` 的 200/401;而核心换肤端点 `POST /skin-changer` 后端**不鉴权**。做法:
1. 本地反代官网,注入 shim + 给前端 bundle 打补丁(挂载即已登录、屏蔽 401 登出);
2. `fetch` 层把 `/login`、`/ping` 等鉴权请求**短路成本地成功**(不发请求,避免后端转发远程挂起);
3. 应用点击“应用”时调用的 `/skin-changer` 本就畅通 → 换肤生效。

## 常见报错
| 报错 | 原因 | 解决 |
|---|---|---|
| `Windows 找不到文件 ...\crack\_run_serve.bat` | 只发了 bat,`crack` 文件夹没跟着走 | 把 `crack` 文件夹放到 bat 同目录(或 VS.exe 同目录) |
| `[X] 找不到 crack 目录` | 同上,新启动器的中文提示 | 同上 |
| `[X] 没检测到 Python` | 没装 Python 3 | 装 Python 3,安装时勾选 Add python.exe to PATH |
| 页面打不开 / 一直转圈 | 前端没起来 | 看同目录 `start.log` 与 `crack\serve.log` |
| 换肤不生效 | VS.exe 未运行(后端离线) | 先开 VS.exe,再刷新页面 |
